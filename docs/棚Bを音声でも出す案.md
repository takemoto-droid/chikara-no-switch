# 棚 B の場面を、音声でも出す案（13便のもと・下書き・先生未確認）

> 伴走チャットの提案（2026-11-05）を受けて、制作の Claude が書いた案です。まだ何も作っていません。先生が選んでから作ります。
> 残し方は今と同じで、「どの出し方のとき力が出たか」だけを残します。「苦手」は書きません。

## 1. 先に分かっていること
- **図の色や形のような手がかりが、音声には無い。** 文の版・図の版は、読み返せます。音声は流れて消えるので、同じ場面でも、覚えておく量がずっと多くなります。
- **要素が多い場面（段階2・席12や当番12）を音声だけで出すと、「聞いた並びを覚えて答える」課題になる。** これは、作り方の決まりの「置かない形」（並びを覚えて答える・復唱する形。既存の検査に似る）に近づきます。先生の見立てのとおり、作れるのは要素が少ない場面だけと考えます。
- 段階1（2×2・4つ）なら、「左前は あおい、右前は けん…」の4つを聞いて答える形にできます。段階3（むずかしめ）はまだ作っていないので、段階3を作るときに、音声に向く形かどうかを一緒に決めます。
- 音声は、読み上げの声が決まってから作ります（声は先生が保留中）。

## 2. 案

### 案ア　測るゲーム（②）の棚 B に「聞いて場面」を足す
- 今の「文で見る／図で見る」に、「聞いて場面をつかむ」を足します。比べるのは、同じ子の「図で見る」と「聞いて」、または「文で見る」と「聞いて」です。
- 段階1の4題だけで作ります。段階2の子には出しません。
- **よい所**：「場面のことは、聞くと分かりやすい子」が見つかるかもしれない。
- **気になる所**：
  - 読む／聞く は、もう棚 A で比べています。棚 B で「聞く」を足すと、同じことを二度測ることに近くなります。
  - ゲームが長くなります（4題ふえる）。
  - 段階2の子には出せないので、子によって比べる組が変わります。
  - 「聞いた並びを覚えて答える」形に近づかないよう、問いは1つにし、聞き返しは今の棚 A と同じ1回までにする必要があります。

### 案イ　⑥ 朝の練習（聞くを育てる）に「聞きながらメモする」を入れる（測るゲームには入れない）
- 「聞く」を育てている子の練習に、場面の音声を聞きながら、図の枠に名前や物を置いていく形を足します。今の「置いてみよう」（図を触る）の部品をそのまま使えます。
- 支えの減らし方（足場かけ → 足場外し）の例：
  1. 図の枠と名前の札があり、聞きながら札を置く（何度でも聞ける）
  2. 図の枠だけあり、聞きながら名前を選んで置く（聞き返しは2回まで）
  3. 聞いたあとで、問いに答える（メモの枠はある）
  4. 聞くだけで、問いに答える
- **よい所**：測る棚を変えないので、比べ方に影響しない。「メモを取りながら聞く」は、教室の連絡を聞くときにも使える形です。
- **気になる所**：練習の段が進む決まり（2回続けて正解が多い）に、メモの正しさを入れるかどうかを決める必要があります（今の「置いてみよう」は、正解の数に入れていない）。

### 案ウ　両方（まず案イ、あとで案ア）
- 案イを先に作り、子どもが「聞きながらメモする」に慣れるかを見てから、案アを考えます。

## 3. 音声の文の例（段階1・B1Y の場面）
> 教室の 席の 話を します。前に 黒板が あります。左前は あおい さん、右前は けん さん、左後ろは さき さん、右後ろは たいち さん です。

問い（案アの場合）：「右後ろの 席は だれ？」→ たいち（選択肢は、あおい・けん・さき・たいち）

## 4. 先生に決めてほしいこと
1. 案ア・案イ・案ウのどれにするか（作らない、も選べます）。
2. 「聞きながらメモする」を、測るゲームではなく ⑥ に入れるか（案イ）。
3. 案イのとき、メモの正しさを、段が進む決まりに入れるか（入れない・入れる）。
