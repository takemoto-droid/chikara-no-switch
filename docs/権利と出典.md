## 音声
- 課題文（読む／聞くの文章と問い）・選んで答える質問・⑥の問題の読み上げは、2便から、前もって作った音声ファイル（`public/onsei/`）を使う。作り方は `scripts/onsei_tsukuru.py`。キーは使っていない。
- 使ったもの
  - Open JTalk（名古屋工業大学 HTS working group ほか、修正 BSD ライセンス）
  - pyopenjtalk（MIT License）：Open JTalk を Python から使うため。辞書（open_jtalk_dic_utf_8-1.11、修正 BSD ライセンス）は初回に自動で取りこまれる。
  - 声：HTS Voice “Mei”（Copyright (c) 2009-2013 Nagoya Institute of Technology, MMDAgent Project Team）。**クリエイティブ・コモンズ 表示 3.0（CC BY 3.0）**。https://creativecommons.org/licenses/by/3.0/
- CC BY 3.0 の表示として、画面のいちばん下に「読み上げの音声：Open JTalk で作成。声 “Mei” © 2009-2013 Nagoya Institute of Technology（CC BY 3.0）」と出している。動画・README にも同じ表示を入れる。
- 前もって作った音声が無い文だけ、ブラウザの読み上げ（Web Speech API）を使う。どの声で読んだかは記録に残す。
- 音声の読み方（読みまちがい）は、先生が聞いて確かめる（先生未確認）。
- 声「Mei」の扱い（先生の決定・5便）：文は自作。声は、ライセンス（CC BY 3.0）で使える道具として使う。表示は上のとおり、画面のいちばん下に出す。
