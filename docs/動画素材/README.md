## 3分の動画（24便で作り、25便〜28便で直した。41便・42便で先生の声と台本 第8版に）

- **提出した動画（41便・42便）**：声は先生の声（通しの録音 1 本を 7 区間に分け、先生の 11/8 14:03 の 4 か所を削り、0.7 秒より長い間を詰めたもの。声そのものは切らず、速さも変えない）。台本は 第8版（26 文）。声の分け方と、文の頭・かけらの頭の秒（`jikoku.json`）は [docs/制作41便/](../制作41便/)。先生の声の文は台本と少し違う所がある（先生のアドリブ）が、画面の字幕と絵は台本のまま（先生の判断）。長さ 2:58.7。

- `npm run douga:tsukuru`（scripts/douga_tsukuru.mjs）で、台本（資料の 23・第6版）どおりの3分以内の動画（1920×1080・30fps・H.264＋AAC）を作ります。mp4 は `.douga/` に置き、Git には入れません（先生に直接渡します）。
- 声は台本の 28 文を合成の声 “Mei”（pyopenjtalk・speed 1.25・文の間 0.28 秒・区間の頭 0.5 秒・要点 6 文の後ろ +0.4 秒・最後の一枚 4 秒）で読みます（scripts/douga_koe.py）。読み違える2語（言ってね・区切って）だけ、合成に渡す読みをかなにしています。字幕は声と同じ文（「クロード」は「Claude」、漢数字は算用数字）を 52px・1 行 22 字までで、「。」で区切った文の途中では枚をまたぎません。
- 画面は、鍵なし（CHIKARA_KEY_NASHI=1）で動かしたアプリの本物の写しです（起・承・結の教室の絵だけ、道具で描きます）。デモ1 の仮説と伝え方は、保存した Claude の文が出ます。次を選んだ理由の記録は、公開デモで Claude が書いた記録（資料 31）を、撮るときだけ端末の覚えに入れて写します。27便から、画面は一律 760×428 の幅（アプリの本物の折り返し）を 2.5 倍で写します（図＋2×2 の測る問題と、先生の画面のデモ1 の全体だけ 960×540）。28便から、2-up（左右 2 枚）に入れる読む・聞く・区切って・深さ-3 の仮説とカードは、900×700 の箱で字が 36px 以上になるよう、480 幅で開いた同じ画面（アプリの本物の折り返し）から写し、図は図の部分だけを切ります。1280 幅で写す画面はありません。字幕・小は、アプリの枠の下・字幕の帯の上の暗い帯（2 行まで）に置き、アプリの枠には重ねません（一コマずつ確かめ、重なれば止まります）。写す範囲に「予備の動き」・鍵・Vercel の表示が入ったら止まります。声の文・字幕・字幕・小・重ねる文は言葉の正本で点検し、1件でもあれば止まります。
- 先生の声に差し替えるとき：`DOUGA_KOE_DIR=<フォルダ>` に `01_ki`・`02_sho`・`03_tenA`・`04_tenB`・`05_tenC`・`06_fukasa`・`07_ketsu`（m4a／mp3／wav）を置いて作り直すと、その区間だけ先生の声になります（無い区間は合成の声。字幕の時刻は、`jikoku.json` があれば文の頭とかけらの頭の秒を使い、無ければ区間の長さを文の字数で割り付けます）。3:00 を超えたら止まります（落とす文は先生が決めます）。
- 要るもの：Playwright と Chromium・ffmpeg・字体 BIZ UDPGothic・pyopenjtalk の入った Python（`python3 -m venv .onsei-env && .onsei-env/bin/pip install pyopenjtalk` のあと `DOUGA_PYTHON=.onsei-env/bin/python npm run douga:tsukuru`）。
