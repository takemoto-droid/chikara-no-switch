# 動画素材（画面写し）

> `npm run douga`（scripts/douga_sozai.mjs）で作りました。1920×1080、画面を 150% に拡大して写しています。
> キーが無いあいだの画面なので、ゲームの理由・仮説・伝え方は「予備の動き（決まった文）」です。キーが来たら、キーを入れて撮り直します（`DOUGA_KEY_ARI=1 npm run douga`）。
> デモの子は、すべて架空の子です。

| ファイル | 場面 |
|---|---|
| 01_ゲーム_次を選んだ理由.png | ゲームで、次の問題を選んだ理由が画面に出る（キーが無いあいだは「決まった順」の文） |
| 02_ゲームのおわり.png | ゲームのおわり：「スイッチカードを見る」 |
| 03_スイッチカードを受け取る.png | スイッチカードを受け取る（強みだけ・枚数は出さない） |
| 04_デモ4_くり返しのカード.png | 3日分のゲームで、くり返し同じ向きの差が出た子のカード（デモの子4・架空） |
| 05_先生の画面_まとめと仮説.png | 先生の画面：まとめと Claude の仮説（参考程度・決めるのは先生） |
| 06_先生の画面_回ごとの表.png | 先生の画面：回ごとの「出し方の差」の表（デモの子4） |
| 07_デモ5_差が出なかった子のカード.png | どの日も差が出なかった子にも、カードが届く（デモの子5・架空） |
| 画面録画_音なし.webm | 上の流れを通した画面録画（音なし） |
