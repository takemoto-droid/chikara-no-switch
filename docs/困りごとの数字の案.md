# README「1. 困りごと」の数字の案（13便のもと・下書き・先生未確認）

> 伴走チャットが原文で確かめた統計（2026-11-05）をもとに、制作の Claude が書いた案です。先生が1つ選んでから README に入れます。
> 守ること：順位・増減は出さない（「この程度の割合で、実際に困っている人がいる」という認知を伝える）。PISA と PIAAC を足し合わせない。人数は推定と分かる書き方にする。学習スタイル説の型の言葉（言葉の正本の「避ける言葉」）は使わない。文科省 2022 は教員の回答にもとづく推定で、医師の判断にもとづく数ではないと添える。

## 今の README（そのまま使える）
- 文部科学省 2022：通常の学級の小中学生のうち、学習面や行動面で著しい困難があると担任などが回答した子は推定 8.8%（中学校 5.6%）。そのうち校内委員会で支援の対象とされたのは 28.7%。

## 案1　文科省 2022 の「困りごとの種類」を足す（いちばん小さい）
足す文：
> そのうち学習面の困難は 6.5% で、種類ごとに見ると「聞く又は話す」2.5%、「読む又は書く」3.5%、「計算する又は推論する」3.4% でした（重なりがあり、合計にはなりません）。授業の中で個別の配慮を受けているのは 54.9% です。

- よい所：作品の「聞く・読む」とそのまま結びつく。出典が今と同じ1つで済む。
- 注意：種類どうしの重なりは概要に無いので、足し算しない。

## 案2　案1 ＋ PISA 2025（15歳の読む力）
足す文：
> 15歳を対象にした国際調査（PISA 2025）では、日本の高校1年生の 18.6% が、読解力で基礎的な水準（レベル2）に届いていませんでした。ここでいう読解力は「自らの目標を達成し、自らの知識と可能性を発達させ、社会に参加するために、テキストを理解し、利用し、評価し、熟考し、これに取り組む能力」です。

- よい所：動画の字幕の基本路線（15歳でも大人でも、決して少なくない）につながる。
- 注意：前回（2022年 13.8%）との比べ・順位は書かない。PISA が測るのは「読む」だけで、聞く・書くは入っていない。人数の推定は、15歳の人口（総務省の各歳の表）を確かめてから（制作の環境からは開けなかった）。

## 案3　案2 ＋ 大人（PIAAC 2023）と「ある調査では」（RST）
足す文：
> 大人（16〜65歳）を対象にした国際調査（PIAAC 2023）では、日本の 10% が読解力でレベル1以下でした（レベル1は、目印がはっきりあれば短い文章から情報を見つけられる段階）。15〜64歳の人口から単純に計算すると、約700万人にあたります（推定）。ある調査（RST）では、中学生の約半数が、推論などの問いでランダムと変わらない正答率でした（任意で受けた人の結果で、全国を代表する数字ではありません）。

- よい所：「15歳でも大人でも」を数字で言える。
- 注意：PISA と PIAAC を足して「合計〇〇万人」にしない。RST は人数の推定に使わない。PIAAC は 16〜65歳なので、人数は近い年齢（15〜64歳）での単純計算だと書く。

## まだ確かめていないこと（制作の環境から公式のページに入れなかった）
- 15歳の人口（PISA の人数の推定に使う）：総務省の人口推計の各歳の表。
- 小中の児童生徒数（文科省 6.5% の人数に使う）：学校基本調査（全国の値）。
- PISA のレベル1（1a・1b・1c）の具体的な中身：国研『生きるための知識と技能』か OECD の報告書本文。字幕の言葉を決める前に確かめる。
