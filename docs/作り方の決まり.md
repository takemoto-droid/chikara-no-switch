# 作り方の決まり（課題と結果の扱い）

> 【下書き】開発の最初に置いた決まり。作りながら直してよい。直したらこのファイルも直す。

## 1. 問題の棚
- 測るための問題は固定し、毎回同じものを使う。問題は先生が確かめた自作のものだけ。
- 棚の中心は、**同じ難しさの短い文章を読む／聞く → 文の正誤判断**の対。
  - 問いは4種類で、内訳をそろえる：本文どおり／言い換え／一語変えて意味が変わる／無関係だが似ている。
- 中心のほかに置く候補
  - 数学の文章題の「場面」だけを問う課題（計算はさせず、条件に合う図や式を選ぶ）
  - 意味のある指示を読んで（聞いて）従う課題
- 対の文章 A・B は、次をそろえる。
  - 文字数・文の数・1文の長さ
  - 漢字の割合・語の難しさ
  - 問いの内訳

## 2. 置かない形（既存の検査に似るため）
- 記号の書き写し、見本の記号探し、散らばった絵に印をつける
- 数字の列の復唱・逆唱・並べ替え、絵の順番の再現、数字と仮名の混ざった列の並べ替え
- 文字・数字・色・物を格子に並べて速く呼称する、非語を速く音読する
- 色の名前の干渉課題、n-back、反応時間の課題
- 画面や説明に、既存の検査や課題の名前を出さない

## 3. 比べ方
- 比べるのは、**同じ子の別の出し方とだけ**。他の子・学年・年齢とは比べない。
- 初回の1組は練習扱いにし、比べる数に入れない。
- 出し方の順番は入れ替える（ABBA など）。どの文章をどの出し方で出すかも入れ替える。
- 読み返し・聞き返し・進める速さの条件を、出し方の間でそろえる。
- 同じ出し方を2回やったときの揺れも記録する。
- 「候補」と出すのは、**揺れより大きい差が、同じ向きに2回以上出たとき**だけ。
- 正答率が5〜8割になる難しさを選ぶ（全問正解・全問不正解では差が見えない）。
- 再チャレンジは「前回と比べて」まで。「伸びた」とは書かない（2回目は練習で上がりやすい）。

## 4. 出し方スイッチの部品
- **読み上げ**：課題文は前もって作った音声ファイルを使う。ブラウザの声は端末ごとに違い、比べた結果に混ざるため。
- **ふりがな**：先生が確かめた、ふりがな付きの本文だけを出す。自動で付けたふりがなを、確かめずに出さない。
- **文の区切り**：文節区切りと、意味のまとまりでの改行まで。細かく切りすぎると、かえって読みにくくなる。
- **フォント**：BIZ UDゴシック・BIZ UD明朝・Klee One（SIL OFL）。UDデジタル教科書体のファイルは同梱しない。名前を指定して、端末にあれば使うだけにする。

## 5. 子どもと Claude
- 子どもが自由に文を打って、Claude と会話する入口は作らない。
- Claude に送るのは、出し方の記録（どの出し方で何問できたか）と仮の番号だけ。名前は送らない。
- 子どもに見せる文は、言葉の正本（[../data/言葉の正本.json](../data/言葉の正本.json)）で点検してから出す。
- AI を使っていることを画面に出す。
- Claude が使えないとき（上限に達したとき）は、決まった順でスイッチを試す予備の動きに切り替える。

## 6. 公開デモ
- データはすべて架空の子ども。
- 入り方は2つ：「保存した結果を見る」と「その場で動かす（回数上限あり）」。
- API キーはサーバー側だけに置く。デモ専用のワークスペースに、月の支出と1分あたりの回数の上限をかける。
- ダミーの子の結果は、「差が出た子」と「差が出なかった子」の両方を用意する。

## 7. 選んで答える質問・チェック項目・スイッチカード（11/3 夕に追加）
- **選んで答える質問**：困りごとの言葉を代わりに用意した問い（例「ノートを書くのは？ → めんどくさい／時間が足りない／何を書くか分からない／書けている」）。タップで答える。問いの文は読み上げも付ける。自由入力は無し。答えは先生の画面に出し、比べる数には入れない。
- **チェック項目**：先生が期末・懇談前に、項目ごとに「当てはまる子」をクラス単位で選ぶ。15〜20項目。すべて「授業で見た事実」の形（例「解けているのにノートが白紙」「個別に聞くと答える」）。症状の言葉は使わない。**点数にしない。基準を作らない。** 当てはまった項目は「気づきの候補」として残るだけ。項目は先生の自作（文科省の調査・市販の尺度を写さない）。
- **スイッチカード**：力が出た出し方が、カードとして残る。全員に1枚以上。枚数は表示しない。「〇〇が苦手」のカードは無い。説明は3つ（これは何か／自分でできる使い方／先生にお願いしてよいこと）。
- **Claude の仮説**：ゲームの結果・選んだ答え・チェック項目を並べて読み、「〇〇のとき力が出ているかも。次に試すなら△△」の形で出す。仮説・確かめた回数・「参考程度・決めるのは先生」を必ず添える。
- **再開**：ゲームは途中で止めて、続きから再開できる（月1回を2〜3回に分けてよい）。
