# 作り方の決まり（課題と結果の扱い）

> 【下書き】開発の最初に置いた決まり。作りながら直してよい。直したらこのファイルも直す。

## 1. 問題の棚
- 測るための問題は固定し、毎回同じものを使う。問題は先生が確かめた自作のものだけ。
- 棚の中心は、**同じ難しさの短い文章を読む／聞く → 文の正誤判断**の対。
  - 問いは4種類で、内訳をそろえる：本文どおり／言い換え／一語変えて意味が変わる／無関係だが似ている。
- 中心のほかに置く候補
  - 数学の文章題の「場面」だけを問う課題（計算はさせず、条件に合う図や式を選ぶ）
  - 意味のある指示を読んで（聞いて）従う課題
- 対の文章 A・B は、次をそろえる。
  - 文字数・文の数・1文の長さ
  - 漢字の割合・語の難しさ
  - 問いの内訳

## 2. 置かない形（既存の検査に似るため）
- 記号の書き写し、見本の記号探し、散らばった絵に印をつける
- 数字の列の復唱・逆唱・並べ替え、絵の順番の再現、数字と仮名の混ざった列の並べ替え
- 文字・数字・色・物を格子に並べて速く呼称する、非語を速く音読する
- 色の名前の干渉課題、n-back、反応時間の課題
  - 06 の棚 E（反応のゲーム）は書き違いだったので、作らない（先生の決定・3便）。楽しさはカードと画面で出す。
- 画面や説明に、既存の検査や課題の名前を出さない

## 3. 比べ方
- 比べるのは、**同じ子の別の出し方とだけ**。他の子・学年・年齢とは比べない。
- 初回の1組は練習扱いにし、比べる数に入れない。
- 出し方の順番は入れ替える（ABBA など）。どの文章をどの出し方で出すかも入れ替える。
- 読み返し・聞き返し・進める速さの条件を、出し方の間でそろえる。
- 同じ出し方を2回やったときの揺れも記録する。
- 「候補」と出すのは、**揺れより大きい差が、同じ向きに2回以上出たとき**だけ。
- 正答率が5〜8割になる難しさを選ぶ（全問正解・全問不正解では差が見えない）。
- 再チャレンジは「前回と比べて」まで。「伸びた」とは書かない（2回目は練習で上がりやすい）。

### 回をまたいで比べる（3便で書き足し）
- 同じ子が、別の日にゲームをした「回」を重ねて持つ（端末のブラウザの中だけ。サーバーには残さない）。
- 回をまたいで比べるのは、**その回の中の「出し方の差」どうし**。素点（正解の数）を回ごとに比べない。2回目は慣れて正解が増えやすいため。
- **その回の向き**：その回の2組の差が、どちらも同じ向き（0 でない）なら、その出し方の向きとする。
- **その回の候補**：上の「候補」の決まり（揺れより大きい差が、同じ向きに2組とも）を満たした回。
- **くり返し出た候補**：ある回で「その回の候補」になり、**別の日の回でも同じ向きの差が出ていて**、どの回にも反対向きの「その回の候補」が無いとき。06 の「1回では決めない」に合わせた決まり。
- カードには「これまでの○回のゲームのうち○回で、くり返し〜」と事実で書く。「伸びた」「上がった」とは書かない。
- 合成データでの割合は [合成データでの確かめ.md](合成データでの確かめ.md) の 3章。
- 6便で、骨（揺れより大きい差が同じ向きに2組で候補・素点は回ごとに比べない）を変えずに、揺れの取り方と別の日の数え方を変えた線を比べた（[線の比べ_6便.md](線の比べ_6便.md)）。挙げられる割合の伸びが小さく、1日の空ぶりが増えるので、**線は変えていない**（揺れは2つの出し方の揺れの大きいほう・反対向きの「その回の候補」があればくり返しにしない）。

## 4. 出し方スイッチの部品
- **読み上げ**：課題文は前もって作った音声ファイルを使う。ブラウザの声は端末ごとに違い、比べた結果に混ざるため。
- **ふりがな**：先生が確かめた、ふりがな付きの本文だけを出す。自動で付けたふりがなを、確かめずに出さない。
- **文の区切り**：文節区切りと、意味のまとまりでの改行まで。細かく切りすぎると、かえって読みにくくなる。
- **フォント**：BIZ UDゴシック・BIZ UD明朝・Klee One（SIL OFL）。UDデジタル教科書体のファイルは同梱しない。名前を指定して、端末にあれば使うだけにする。

## 5. 子どもと Claude
- 子どもが自由に文を打って、Claude と会話する入口は作らない。
- Claude に送るのは、出し方の記録（どの出し方で何問できたか）と仮の番号だけ。名前は送らない。
- 子どもに見せる文は、言葉の正本（[../data/言葉の正本.json](../data/言葉の正本.json)）で点検してから出す。
- AI を使っていることを画面に出す。
- Claude が使えないとき（上限に達したとき）は、決まった順でスイッチを試す予備の動きに切り替える。

## 6. 公開デモ
- データはすべて架空の子ども。
- 入り方は2つ：「保存した結果を見る」と「その場で動かす（回数上限あり）」。
- API キーはサーバー側だけに置く。デモ専用のワークスペースに、月の支出と1分あたりの回数の上限をかける。
- ダミーの子の結果は、「差が出た子」と「差が出なかった子」の両方を用意する。

## 7. 選んで答える質問・チェック項目・スイッチカード（11/3 夕に追加）
- **選んで答える質問**：困りごとの言葉を代わりに用意した問い（例「ノートを書くのは？ → めんどくさい／時間が足りない／何を書くか分からない／書けている」）。タップで答える。問いの文は読み上げも付ける。自由入力は無し。答えは先生の画面に出し、比べる数には入れない。
- **チェック項目**：先生が期末・懇談前に、項目ごとに「当てはまる子」をクラス単位で選ぶ。15〜20項目。すべて「授業で見た事実」の形（例「解けているのにノートが白紙」「個別に聞くと答える」）。症状の言葉は使わない。**点数にしない。基準を作らない。** 当てはまった項目は「気づきの候補」として残るだけ。項目は先生の自作（文科省の調査・市販の尺度を写さない）。
- **スイッチカード**：力が出た出し方が、カードとして残る。全員に1枚以上。枚数は表示しない。「〇〇が苦手」のカードは無い。説明は3つ（これは何か／自分でできる使い方／先生にお願いしてよいこと）。
- **Claude の仮説**：ゲームの結果・選んだ答え・チェック項目を並べて読み、「〇〇のとき力が出ているかも。次に試すなら△△」の形で出す。仮説・確かめた回数・「参考程度・決めるのは先生」を必ず添える。
- **再開**：ゲームは途中で止めて、続きから再開できる（月1回を2〜3回に分けてよい）。

## 8. 見つけて、育てて、また見つける（7便・06 第3.1版で書き足し）
- **教科に持ちこまない**：HR と朝の時間だけで使う。教科の問題・小テスト・授業のプリントは入れない。
- **難しさの段階**：棚 A・B・C に段階1（やさしめ）と段階2（ふつう）を置く。はじめの練習の正解率で段階を選び、組の途中で「ほぼ0／ほぼ全部正解」なら、次の組から段階を変える（変える前の組は練習扱い）。**比べるのは同じ段階の中だけ。** 段階は子どもに見せない。
- **⑥ 育てる**：得意な出し方を支えにして、もう一方の出し方を段1〜4で練習する（足場かけ → 足場外し）。段が上がるのは、ゲームの中の事実（2回続けて正解が多い など）だけ。段は下がらない。「今日はやらない」を選べる。記録は本人のもの。
- **⑦ また見つける**：②の短い版（3つの組・前回と同じ段階から）。回をまたいで比べるしくみ（3章）をそのまま使う。
- **カードのレベル**：見つけたカードは「みつけた → たしかめた → しっかり」、育てるカードは段1〜4。カードごとで、上限があり、下がらない。合計・順位・枚数は出さない。
- **置かない練習**：間違い探し・覚えて答える・目で追う（数字タッチ）は入れない。既存の訓練教材も写さない。
- **段が進む決まり（7便で置いた値・仮）**：練習のひとつ（2〜3分）で、問いの3分の2以上が正解なら「正解が多い」。同じ段で「正解が多い」ひとつが2回続いたら次の段へ（間に少ないひとつがあれば数え直す。日をまたいでも続けて数える）。読む・聞くの段3 は、支えのボタン（聞く／文を見る）を押したのが2回以下のひとつだけを数える（06 の決まり）。読み上げが使えなかったひとつは数えない。段4 が上限で、段4 に来たら育てるカードは一人前。⑦ で、練習を始めた後の日に支えの出し方の差が出なくなったときも一人前にする。
- **今日の練習の選び方**：育てる出し方は見つけたカードから（聞く→読む・読む→聞く・図→文・区切って→一気に。区切っては練習しない）。見つからない子は本人が選ぶ（本人の好み）。いくつかあるときは、練習した日がいちばん少ないものを選ぶ（予備）。Claude は、この候補の中から選び、理由を言う。段は変えない。
- **練習の文の難しさ**：その子のいちばん新しい HR の、その棚の最後の段階（1 か 2）に合わせる。練習の文は測る棚とは別のファイルにする。
- **Claude の文を端末に覚える（10便）**：公開デモでは Claude を呼べる回数に上限があるので、Claude が書いた文（仮説・伝え方・期間の計画・今日の練習の理由）は端末の中（記録と同じ場所）に覚え、同じ画面を開き直したときは呼ばない。呼び直すのは、(1) 先生が「もう一度書いてもらう」を押したとき、(2) 元になるもの（ゲームの回とその結果・練習の記録・チェック項目・学校の設定）のどれかが変わったとき、だけ。覚えた文の近くには、書いた日と「この文は端末に覚えています」を小さく出す。予備の動きの文は覚えない（鍵が使えるようになったら、本物の文に置き換わるように）。端末ごとに覚えるので、別の人が初めて開いたときは1回呼ぶ。
