# 専門家の意見について

> **この文書に出てくる「専門家」は、Claude が専門家の役を演じて検討したものです。本物の専門家の意見ではありません。このアプリは、専門家（特別支援教育・心理など）の監修を、まだ受けていません。**
> 扱う内容が繊細なので、学校で実際に使うには、専門家の助言と協力が必ず要ります（README「8. 限界」・先生の判断 11/8 00:25）。

この文書は、制作の中で Claude に役を立てて検討させた記録が「何を検討して、何を決めたか」を、要点だけ書いたものです。どの記録でも、**決めたのは先生**です。元の記録は資料リポジトリにあります（「専門家会議」の名前の文書と、動画の批評・検収の文書）。

## 1. なぜ役を立てたか
- 一つの目だけで作ると、見落としが出ます。そこで、立場の違う目（読み書きに困難のある子の立場・測り方の倫理・画面の設計・批判役 など）を、Claude に別々に演じさせ、意見書を独立に書かせました。司令塔（相談役の Claude）がそれをまとめ、先生に案として出しました。
- 本物の専門家の代わりではありません。「こういう見方もある」という点検の道具として使いました。

## 2. 何を検討して、何を決めたか

### 2-1. 画面と測り方の再考（2026-11-04）
- **役**：特別支援教育・ユニバーサルデザインの専門家／心理検査の倫理と教育測定の専門家／中学生向け学習ゲームと画面設計の専門家／批判役（中学校の学年主任・AI に懐疑的・審査基準を読み込んでいる）。いずれも Claude が演じた。
- **きっかけ**：先生 11/4 16:23「文字が多くて一人でテストすることが難しい生徒もいるかも」・時間やレベルの段数についての先生の考え。
- **会議の案**：子どもの画面の文字を減らす／解くのにかかった時間はカードの材料にしない／レベルの段数を増やさない／抽象的な図形の操作は ② 見つけるに入れない／文と図の棚の中身が中学 1 年の数学の問題に見えるので、生活の場面に差し替える。
- **先生の裁定（11/4 16:40）**：文字を減らす「受け入れます」／棚の差し替えは生活の場面を基本に／時間はカードに使わない「受け入れます」／レベルは増やさない「受け入れます」／図を触る操作は「作成したいです」（⑥ 育てるの中で）。→ 12便。
- 司令塔は先生に、間違い探しは入れない（検査に似て、練習の効果で本物の検査を狂わせうる）と補足しました。

### 2-2. 配色と動画の見せ方（2026-11-06）
- **役**：特別支援教育・ユニバーサルデザイン／画面と色の設計・動画の見え方／審査員・3 分動画の作り手／批判役。いずれも Claude が演じた。
- **きっかけ**：先生 11/6 22:45「アプリの画面の色がほとんど同じ色で、動画にしたら、あまり中身がよくわからなかった」。
- **会議の案**：出し方ごとに色を割り当てない（色だけで見分ける作りにしない・「自分の色＝型」に見えないように）／派手にしない／直すのは色の数ではなく、境界と字の大きさ／動画の字幕を大きくし、画面に寄る。
- **先生の決定（11/6 22:55 ごろ）**：アプリの CSS は「境界だけ」／動画の道具の直しは全部入れる／声は合成の声で完成形を先に作る。→ 26便。

### 2-3. 動画の批評と検収（2026-11-06〜11-07）
- **役**：映像ディレクター（台本づくりを見ていない別の目）／総合プロデューサー／読みづらい視聴者の立場のユニバーサルデザインの専門家／アプリ画面の設計者。いずれも Claude が演じた。
- **きっかけ**：先生 11/6 23:34「動画のプロが見て、…再度批評し、改善点があれば出来るだけの改善はしたい」、11/7 07:30「総合的なプロデューサーとしてこの動画を検収してほしい」。
- **決めたこと**：声の文の直し 7 つを先生が採用（11/6 23:50）。26便の動画の検収（合・条件付き 7/10）で見つかった致命 3 つを 27便で直し、再検収で 7.5/10（[検収のしかた.md](検収のしかた.md)）。
- 動画の見た目の決まり（地の色・字の大きさ・1 場面 1 つの主な考え）は、先生が見本の画像を見て選びました（11/7 13:25・16:10）。

### 2-4. 審査員の目での見直し（2026-11-04・本部）
- **役**：9 つの立場（Claude の活用・事業・管理職・保護者・中学生本人・教育測定・法務・動画の編集・他の参加者）。本部（制作の Claude）が演じた。
- **決めたこと**：先生の判断がいらないものだけを直した（README に「決まった文と Claude の文はどこが違うか」、安全とプライバシーの文書に「聞かれたときの答え」の下書き、概要に「医療や専門の検査の代わりでもありません」）。先生が決めることには触れていない（[制作の記録.md](制作の記録.md) の「12便のあと」）。

## 3. 読むときの注意
- ここに書いた「専門家」「批判役」「プロデューサー」などは、すべて Claude が演じた役です。資格や経験のある人が検討したものではありません。
- 会議の結論は「案」で、採るかどうかは先生が決めました。採らなかった案もあります（例：子どもの画面と先生の画面で地の色を分ける案は採っていない）。
- 研究の出典にもとづく部分は [調べたこと.md](調べたこと.md) と [科学的根拠のあること_ないこと.md](科学的根拠のあること_ないこと.md) にあります。役の意見と、出典で確かめた事実を、混ぜないでください。
