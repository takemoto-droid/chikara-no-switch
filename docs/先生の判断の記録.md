> 先生の判断と、司令塔（相談役の Claude）の判断・提案は、書き分けています。元の資料に無いことは書いていません。

## 3. 全体の見通し（11/6 11:10）
元の資料：`20_全体の見通し_締切まで_20261106.md`（司令塔の文書）。

- **司令塔の判断（先生に伝え済み）**：11/6 から機能を増やさない（凍結）。カードの絵・読み上げの声の差し替え・文と図の棚の音声版・案内の絵は作らず、README の「これから」に残すだけ（20便で記録）。
- 理由（司令塔の見立て）：足りないのは提出物そのもの（動画・概要の確定・README の食い違い・提出の手続き）で、新しい機能を足すと、通し確認と README の付け直し、動画の撮り直しが連鎖するため。
- この凍結の例外は、先生が決めました：21便の小さな直し 3 つ（11/6 13:33「直します」）・30便の架空の子の名前・36便の短い体験（11/8 03:50）。
