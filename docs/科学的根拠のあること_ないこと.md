# 科学的根拠のあること／ないこと

> 【下書き】出典は開発の最初（2026-11-03）に確かめたもの。提出の前に、もう一度リンクを確かめる。

## このアプリがしないこと：型を当てること
- 「視覚型・聴覚型」などの学習スタイルを決めて、それに合わせて教えると学びが良くなる、という考えがあります。この考えは、厳密な研究では支持されていません（Pashler ほか 2008）。
- チカラのスイッチは、型を決めません。好みも聞きません。同じ難しさの問題を出し方だけ変えて解き、**その子の結果の差**を確かめます。差が出なければ「差なし」と返します。

## 研究で分かっていること（このアプリの作りの土台）
- **一人ずつ、出し方を変えて確かめる**：配慮ごとの効果を、形のそろった短いテストで一人ずつ確かめる方法は、前から研究されています。
  - 米国の DATA（Fuchs ほか 2000）では、データにもとづく決め方の方が、教師の勘よりよく当たりました。
  - 国内の URAWSS II にも、「自分で読む」と「代読」を比べる使い方があります。
  - チカラのスイッチは、この考え方を HR と朝の時間の短いゲームにしたものです。違いは、他の子とは比べず、同じ子の別の出し方とだけ比べる点です。
- **読み上げ**：読みに困難のある子の群では、読解の点が上がるという報告があります（Wood ほか 2018、d=0.35）。ただし、同じ子で「あり／なし」を比べた研究だけでは、差は小さく有意ではありませんでした（d=0.15）。効く子も効かない子もいるので、一人ずつ確かめます。
- **ふりがな**：小5〜中2の実験では、ふりがなで読解の点は有意に上がりませんでした（Arai ほか 2018）。差が出ないのが、ふつうの結果です。
- **文の区切り**：文節で区切ると読みやすくなる子もいますが、個人差が大きく、研究者は本人が選べるようにすることを勧めています（村田、科研 19H01705）。
- **図を添える**：図は多くの人に効く工夫です（マルチメディアの原理）。だから、図で点が上がっても「この子は図の子」とは言いません。

- **カードが表すもの**：スイッチカードは「読む／聞く」「文で見る／図で見る」「一気に／区切って」の3つの比べの結果だけを表します。得意・不得意の全体を表すものではありません。全体は、先生の画面で、結果・選んだ答え・授業での観察を合わせて見ます。書いて答える・口で答える出し方は、測っていません。

## いちばん近い先例と、ちがい（7便で足した）
- **多層指導モデル MIM**（海津ほか 2008）：通常の学級で、全員に2分ほどの見取りをし、全員・小さな集まり・個別の3つの段で指導し、月1回ほど進み具合を確かめます。小学1〜2年の特殊音節の読みが対象です。この作品にいちばん近い先例です。
  - ちがい：対象（小学1年の読み／中学生の出し方）、測るもの（読みの速さや正確さの値／本人の中の出し方の差）、段の決め方（クラスの中での位置／本人の中の候補）。
  - MIM デジタル版の手引きには「デジタル版を子どもに渡せば読みの力が向上すると考えるのは誤り」とあります。この作品の「決めるのは先生」と同じ立場です。
- **コグトレ**（宮口 2015〜）：覚える・数える・写す・見つける・想像する練習で、学校や通級で広く使われています。科研の研究（2017〜20）では「配慮が必要な児童の正答率がクラス平均に近づいた」まで。学力への広がりは示されていません。「小学校高学年で正答率は頭打ち、中学でも変わらない」との記述もあります。**この作品は、こうした教材を写しません**（検査に似た課題で練習すると、本物の検査の結果が本来より高く出て、支援の判断を狂わせうるため）。
- **ビジョントレーニング**：眼科での確認が前提なので、入れません。

## 練習（⑥育てる）の作りの根拠
- **足場かけと足場外し**：学ぶ人ができない所を支え（足場かけ）、できるようになるにつれて支えを外していく（足場外し）考え方は、Wood・Bruner・Ross（1976）以来、学習の研究で広く支持されています（原典は、制作の側ではまだ読んでいません）。
- この作品の練習は、別のゲームをして広がりを期待するものではありません。**苦手な出し方そのものを、得意な出し方を支えにして、支えを減らしながら練習します。** 言えるのは「ゲームの中で、支え無しでもできる量が増えた」までです。学力への効果は、確かめていません。

## 「力が伸びる」とうたわない理由
- 脳トレーニングは、練習した課題そのものは上達します。でも、ほかの力に広がる証拠は乏しいとされています（Simons ほか 2016）。
- 同じ号の論評（McCabe・Redick・Engle）も、メタ分析（Melby-Lervåg・Redick・Hulme 2016）を引いて、これまでの認知トレーニングには、別の課題への広い効果が見られないと結論しています。
- 米国では、学校の成績や集中力が上がるとうたった脳トレや子ども向けゲームが、根拠のない宣伝として FTC に処分されました（Lumosity 2016、Jungle Rangers 2015）。
- このアプリは、効果をうたいません。返すのは「この出し方のとき、どうだったか」という事実だけです。
