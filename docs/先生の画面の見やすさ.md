# 先生の画面の見やすさ（4便で整えた考え方）

> 下書き（先生未確認）。並べ方は、先生が使ってみて直してよい。

先生の画面は、懇談の前や授業のあとに「この子に、次に何を試すか」を決めるための画面です。だから、上から次の順に並べました。

1. **まとめ：いま言えること**（いちばん上）
   棚ごとに1行で「くり返し出た候補」「この日だけの候補」「差なし」「まだ比べていない」のどれかを出します。子どもが持っているカードの名前もここに出します。
2. **Claude の仮説**（まとめのとなり）
   「参考程度・決めるのは先生」「確かめた回数」を、いつも付けます。PC の幅では、まとめと仮説を横に並べ、ひと目で見られるようにしました。
3. **次へ進むボタン**（⑤ 伝え方・カード・引き継ぎの記録）
   まとめと仮説を読んだら、すぐ次に進めるように、ここに置きました。
4. **授業の手がかり**：選んだ答え・チェック項目で当てはまったもの（PC の幅では横に並べる）
5. **数字の根拠**：回ごとの「出し方の差」の表、いちばん新しい回のくわしい表、読み上げの声
6. **ゲームで Claude が次を選んだ理由の記録**（たたんでおく）

決めたこと
- 細かい数字は後ろに置きました。数字は、まとめや仮説が何をもとにしているかを確かめたいときに見るものだからです。
- スマホの幅では、上の順に1列で並びます。PC の幅（900px 以上）では、先生の画面だけ横に広く使い、2つずつ横に並べます。
- 子どもの画面・保護者の画面は、今までどおり1列で、字を大きくしています。
