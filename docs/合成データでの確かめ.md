## 2. 「候補」の決まりのふるまい

「候補」は、同じ出し方を2回やったときの揺れより大きい差が、同じ向きに2回出たときだけ。

| 合成の子の設定 | 読む／聞く で候補 | 文で見る／図で見る で候補 | 一気に／区切って で候補 | どれか1つの棚で候補 |
|---|---|---|---|---|
| どの出し方でも力が同じ（本当は差が無い） | 7.6% | 8.0% | 7.1% | 21.0% |
| 聞く・図・区切ってが効く（効き目 0.5） | 8.7% | 8.9% | 8.8% | 24.2% |
| 聞く・図・区切ってが効く（効き目 1） | 11.1% | 10.2% | 12.5% | 29.9% |
| 聞く・図・区切ってが効く（効き目 1.5） | 16.6% | 13.0% | 16.4% | 39.2% |

- 1行目は「空ぶり」（本当は差が無いのに候補になる割合。向きはどちらでも数えた）。棚1つでは1割未満だが、3つの棚のどれかでは2割ほどになる。カードと仮説を「この日の」結果として書くのは、このため。
- 2行目からは、本当に差がある合成の子で、候補になる割合。1回のゲームでは見のがしも多い。だから「1回では決めない」「別の日にもう一度」が要る。
- 効き目 1.0 は、正答率がおよそ6割の子なら8割近くまで上がるくらいの差（仮の値）。

## 3. 回をまたいで比べる（3便）

同じ合成の子が、別の日にゲームを1〜3回したとき。回を重ねるごとに、どの出し方も同じだけ慣れて正解しやすくなるようにした（仮の値 0.3）。

- 「どれかの回でその回の候補」：1回ごとに見て、どれか1回でも「候補」になった割合。
- 「くり返し出た候補」：ある回でその回の候補になり、別の日の回でも同じ向きの差が出て、反対向きの候補が無いとき（docs/作り方の決まり.md の 3章）。

### 選んだ線と、そのわけ（6便）

**5便の線のまま、変えない。** 実装した線の表（README・合成データでの確かめ）も、5便の線の数字のまま。

- X2 の骨（揺れより大きい差が同じ向きに2組で候補・素点は回ごとに比べない など）の中で試せた線では、差がある子を挙げられる割合は、いちばんよい線（線6・線7）でも 1.4 倍ほど（3日分で 10% → 15% ほど）にしか上がらなかった。
- その代わりに、1日のゲームで差が無い子に「その日の候補」が出る割合が、どれか1つの棚で 2割ほどから 3割台に増えた。「この日の」カードが、根拠の弱いまま渡りやすくなる。
- 別の日の「同じ向き」をゆるく数える線（線3・線4）は、挙げられる割合は上がるが、決めつけなかった割合が 6〜7割まで下がる。
- 挙げられる割合をはっきり上げるには、骨の外のことが要る：1組の問いの数を増やす（今は4問、図は2問。06 の3章の棚の形に触れる）か、ゲームをする日を増やして、長く続けたときの数え方（たとえば「新しい3日分まで」）を人で試して決めること。どちらも先生が決めること。
- 問いの数を増やす効き目は、合成データで1つだけ確かめた：図の棚の問いを1場面2問から4問にすると（5便の線のまま・3日分）、図で見るで差がある子を挙げられる割合が 6.9% → 14.6%、決めつけなかった割合は 91.4% → 89.2%（問題を足したときの別の試し。この表には入れていない）。
- **案（先生が決める）**：(1) 5便の線のまま（いまの形）。(2) 線6 にする（挙げられる割合 1.4 倍ほど・1日の空ぶりが 2割ほどから 3割台に増える）。(3) 図の棚の問いを1場面2問から4問に増やす（問題を足す。時間が延びる）。(4) 長く続けるときは「新しい3日分まで」を見る（線11。人で試してから）。

### 選んだ線と、そのわけ

- **練習（読む／聞く 2つ・8問）の正解が 3/8 以下なら段階1から。1組目が「ほぼ0（1/8 以下）」なら段階1へ、段階1で「全部正解」なら段階2へ、次の組から変える（変える前の組は練習扱い）。**
- 段階を使うと、ちょうどよい割合が 4割ほどから5割ほどに、力の低い合成の子では ほぼ0 から 4人に1人ほどに上がる。その代わり、決めつけなかった割合は 2ポイントほど下がる（上の表）。4/8 にしても、ちょうどよい割合はほとんど変わらず、段階1で比べる子が半分になる。2/8 では、力の低い子でちょうどよい割合が少し下がる。
- 組の途中の切りかえは、表ではちょうどよい割合をほとんど変えない。それでも入れたのは、06 の決まり（ほぼ0・ほぼ全部正解の組は比べにくい）に合わせ、正解がほとんど無いまま比べることを避けるため。
- 段階3（むずかしめ）は Should で、まだ作っていない。9割以上できる子は、段階2のまま比べる（「比べにくかった」と先生に出ることがある）。
