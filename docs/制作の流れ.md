# 制作の流れ（便ごとの一覧）

> この文書は、「チカラのスイッチ」を作った順番を、便（作業のまとまり）ごとに 1 行ずつ並べた一覧です。何を作ったか・なぜか・コミット番号・検収の結果が分かります。
> 言葉（便・投げ文・検収・司令塔・本部）の意味は [docs/README.md](README.md) の「言葉の説明」にあります。くわしい中身は [制作の記録.md](制作の記録.md)（5便から）にあります。

## 読み方
- **日付**：コミットの日時を日本時間にしたもの。
- **何を**：その便で作ったこと・直したこと（要点だけ）。
- **なぜ**：きっかけ。先生の言葉・司令塔の検収・Claude が役を演じた会議など、誰の指摘・どんな気づきかを書きます。かっこの中は元の資料（資料リポジトリの投げ文の番号など）です。
- **コミット**：本体のリポジトリのコミット番号。便の中で複数あるときは、最初と最後を「〜」でつなぎます。
- **検収の結果**：司令塔（相談役の Claude）が確かめた結果。元の資料に無いものは「記録なし」と書き、想像で埋めていません。くわしくは [検収のしかた.md](検収のしかた.md)。
- 投げ文の番号と便の番号は別のものです（例：投げ文 46 ＝ 37便）。
