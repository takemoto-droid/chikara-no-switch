# チカラのスイッチ　概要

> 下書き（先生未確認）。README の「困りごと」「何をするか」をもとに、制作の Claude が書きました。言い回しは先生が直してください。

## 短い版（200字ほど）

困りごとを自分では言葉にできない中学生は、授業で困っていても「困ったら言ってね」の一言では声を上げられず、機会がなければ何も解決しないまま過ぎていきます。チカラのスイッチは、授業の中の短いゲームで、同じ難しさの問題を「読む・聞く」「文で見る・図で見る」「一気に・区切って」と出し方だけ変えて解き、その子の中で力が出た出し方を「スイッチカード」として本人に渡します。比べる相手は他の子ではなく、同じ問題を別の出し方で解いた自分です。Claude は、次に試す出し方を理由つきで選び、結果・選んで答えた質問・先生の気づきを並べて読んで「〇〇のとき力が出ているかも」という仮説を下書きします。決めるのは先生です。

## 長い版

### だれの、どんな困りごとか
困りごとを自分では言葉にできない中学生は、授業で困っていても、たずねられる機会がなければ、何も解決しないまま過ぎていきます。「困ったら言ってね」と声をかけても、自分から言える子はほとんどいません。でも、たくさん質問すると答えてくれます。解けているのにノートは白紙、文章題では手が止まるのに図は描ける――そういう子は、どの教室にもいます。

### 何をするか
HR と朝の時間を使う「見つけて、育てて、また見つける」の道筋です。教科の授業には持ちこみません。
1. **案内**：何をするか、何をしないかを、子どもと保護者に先に伝えます。AI を使っていることも伝えます。
2. **見つける（HR）**：同じ難しさの問題を、出し方だけ変えて解きます。難しさは、その子に合う段階を選びます。途中に、困りごとの言葉を代わりに用意した質問があり、タップで答えます。次にどの問題を出すかは、Claude が理由をつけて選びます。
3. **スイッチカード**：力が出た出し方が、カードとして本人の手元にたまります。強みだけを書き、全員に届きます。比べた2つの出し方と、レベルを添えます。カードは「出し方の3つの比べ」だけを表すもので、得意・不得意の全体は、先生の画面で結果・答え・観察を合わせて見ます。
4. **先生の画面**：本人の中での比べ方、選んだ答え、先生が気づいたこと、練習の記録、Claude の仮説（参考程度・決めるのは先生）、学校の設定と期間の計画を見ます。
5. **伝え方**：懇談で先生が口で言うための下書き、カードの説明、先生どうしの一言、HR の冒頭の話を Claude が下書きします。
6. **育てる（朝の練習）**：得意な出し方を支えにして、もう一方の出し方を、支えを少しずつ減らしながら練習します。「今日はやらない」も選べます。
7. **また見つける**：学校の設定の間隔で、短い HR をもう一度します。育てたカードが一人前になり、見つけたカードのレベルが上がります。

### 大事にしていること
- 他の子とは比べません。同じ子の、別の出し方とだけ比べます。
- 1回では決めません。別の日にも同じ向きの差が出たかを見ます。
- 学び方の型を決めません。医療や専門の検査の代わりでもなく、その手前を受け持ちます。
- 子どもが自由に文を打つ入口はありません。記録は端末の中だけに残し、名前は AI に送りません。
