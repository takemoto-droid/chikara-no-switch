# カードの絵の案と、立場を分けた見直し（13便のもと・下書き・先生未確認）

> 下書き（先生未確認）。絵はすべて制作の Claude が自作した線の絵（SVG）です。アプリにはまだつないでいません。先生が1つ選んでから入れます。
> 見本：[一覧.html](一覧.html)（画像は [一覧.png](一覧.png)）。絵のもとは [e.mjs](e.mjs)、一覧は `node docs/カードの絵の案/tsukuru.mjs` で作り直せます。

## 1. 何を表す絵か（考えたこと）
- 絵は「その出し方」を表す。人の性格や力の大きさは表さない。
- 体の部位（耳・目・口・手・頭）は描かない。「聞いて」は耳ではなく音の出る道具や音の波で、「読んで」は目ではなく本で表す。
- 「どれでも」「ためした」は、何もできなかった印に見えないようにする（空っぽ・×・下向きの形を使わない）。
- 優劣に見える形（メダル・星の数・はしご・上向きの矢印の重なり）は使わない。レベルは今の ●○○ のままにする。

## 2. 調べたこと（出典は docs/権利と出典.md）
- **色だけに頼らない**：自治体のカラーユニバーサルデザインの手引きは、色の違いに加えて、形・模様・輪郭・文字でも伝えることを勧めている。文部科学省は、色の見え方が他の人と違う子が学級にいる前提で配慮する資料を出している。
- **形のコントラスト**：WCAG 2.1 の 1.4.11（文字でないもののコントラスト）は、意味を伝える図に、まわりとの差 3：1 以上を求める。1.4.1 は、色だけで情報を伝えないことを求める。
- **ピクトグラムの考え方**：伝えたい物をできるだけ単純な形にする。案内用図記号の規格（JIS Z 8210・JIS Z 8211）では、小さく使うときの最小の大きさも決めている。

## 3. 3つの案
| 案 | 中身 | よい所 | 気になる所 |
|---|---|---|---|
| 案1 道具 | スピーカー・本・図・文の行・区切った箱・長い帯・4つの印・道すじ | 名前を読まなくても、何のカードか見当がつく | 「どれでも」の4つのチェックの印が「全部正解」に見えるおそれ（チェックをやめ、4つの小さな道具の絵に替える案もある） |
| 案2 場面 | 机の線の上に、道具や紙を置いた絵 | 「教室で使う場面」が伝わる。やわらかい | 24px では細部がつぶれやすい。机の線が全部に入り、カードどうしの差が小さく見える |
| 案3 記号 | 波・線・形・点だけ | 24px でもいちばん見分けやすい。白黒でも差がはっきり | 意味を名前と一緒に覚える必要がある。「読んで」の記号は、絵だけでは分かりにくい |

**数えたこと**：どの案も、カードの色の上の白い線は、白との差が 4.9：1〜6.9：1 で、3：1 を超える。図でスイッチ（#7a4fa0）と文でスイッチ（#5a4fa0）はカードの色がほとんど同じで、色だけでは区別しにくい。3つの案とも、この2枚は絵の形がはっきり違う。

## 4. 立場を分けた見直し（制作の Claude が役を分けて書いた。本物の専門家の意見ではない）
- **特別支援教育**：形が単純な案1か案3がよい。案3は、カードの名前と絵を何度か一緒に見るうちに覚えられる。案2は細かく、見る力に負担がかかる子もいる。「どれでも」のチェックの印は、正解の印に見えるので避けたい。
- **スクールカウンセラー**：どの案も人を描いていないので、「自分はこういう人」という見え方になりにくい。「ためした」が下向きや空っぽに見えないことが大事で、3案とも満たしている。
- **美術**：案1は線の太さがそろっていて、カードの名前と並べても強すぎない。案3は小さいアイコンとして最も強い。案2は大きく使うときだけ向く。
- **保護者**：案1は、カードを見ただけで「聞いて考えるときに力が出たのね」と分かりやすい。記号（案3）は説明がないと伝わりにくい。
- **中学生本人（想像）**：案1・案3はすっきりしていて、子どもっぽくない。案2は少し幼く見えるかもしれない。

## 5. 先生に決めてほしいこと
1. 案1・案2・案3のどれにするか（組み合わせてもよい。たとえば案1の形を基本に、「どれでも」だけ別の絵）。
2. 案1にするなら、「どれでも」のチェックの印を替えるか。
3. 絵をカードのどこに置くか（名前の左・右上の角 など）。決まったら、カードの画面・先生の画面・伝え方の画面で同じ絵を使い、代替テキストを付けて入れます。
