# 読み上げの声の聞き比べ（13便のもと・下書き・先生未確認）

> 実機で「ナレーションの声が機械的に聞こえる」と分かったので、見本を3つ作りました。制作の Claude は音を聞いて良し悪しを決められないので、先生が聞いて選んでください。

| ファイル | 作り方 |
|---|---|
| [1_いまの音声.mp3](1_いまの音声.mp3) | 今アプリで使っている作り方（Open JTalk・声 “Mei”・速さ 1.0・24kHz／40kbps に縮めている） |
| [2_少しゆっくり_音質を上げた.mp3](2_少しゆっくり_音質を上げた.mp3) | 速さ 0.92。縮め方をゆるめた（48kHz／96kbps。声のもとの音質のまま） |
| [3_ゆっくり_声を少し低く.mp3](3_ゆっくり_声を少し低く.mp3) | 速さ 0.9・声の高さを半音下げた。音質は 2 と同じ |

文は、棚 A の「町の図書館の交換会」の本文です。

## 分かっていること
- 今の音声は、ファイルを小さくするために 24kHz／40kbps に縮めていて、声のもと（48kHz）より音がこもる。2・3 の作り方にすると、音声のファイルの合計は 3.3MB から 8MB ほどに増える見込み。
- Open JTalk の声は、どう調整しても、人の声のようには聞こえない。もっと自然な声にするには、別の読み上げの道具（声ごとに利用の決まりやクレジットの書き方がある）を使うことになる。それは先生が決めることなので、制作は調べるだけにしている。
- 端末の声（ブラウザの読み上げ）に切りかえる案は取らない。端末ごとに声が違うと、読む／聞くの比べに端末の差が混ざるため（2便からの決まり）。

## 先生に決めてほしいこと
1. 1〜3 のどれにするか（2 か 3 を選んだら、全部の音声を作り直す）。
2. 別の読み上げの道具も調べるか（調べるなら、利用の決まりを確かめてから見本を作る）。
