## 文章のそろえ方（1・3 を確かめるときの目安）
`node` で数えた値（2便の時点）。

| 文章 | 文字数 | 文の数 | 漢字の割合 |
|---|---|---|---|
| A0a（練習） | 98 | 4 | 30.6% |
| A0b（練習） | 104 | 4 | 33.7% |
| A1 | 112 | 4 | 33.9% |
| A2 | 101 | 4 | 31.7% |
| A3 | 108 | 4 | 30.6% |
| A4 | 110 | 4 | 30.9% |

- C（一気に／区切って）の連絡4つ（5便で作り直し）：C1 98字・漢字 32.7%／C2 101字・37.6%／C3 109字・31.2%／C4 97字・35.1%。どれも前おき1文＋中身の文4つで、問いはその番目の文に答えがある（`npm test` で確かめる）。
- 語の難しさは、まだ機械では測っていない。先生の目で確かめてほしい。
- 正答率が5〜8割になるかは、合成データで見ただけ（[合成データでの確かめ.md](合成データでの確かめ.md)）。本当の難しさは、大人や子どもで試すまで分からない。

## ゲームにかかる時間の見積もり（6便・j。まだ人で測っていない）
問いの数（読む／聞く 16＋練習 8・文で見る／図で見る 8・一気に／区切って 16・選んで答える質問 4）から見積もった幅です。**実測は先生か相談チャットが行う。**

| 棚 | 中身 | 1つあたりの見積もり | 合計の見積もり |
|---|---|---|---|
| 読む／聞く | 文章6つ（練習2つを含む）・各4問 | 読む（または聞く）20〜30秒＋問い4つで30〜40秒 | 5〜7分 |
| 文で見る／図で見る | 場面4つ・各2問 | 読む20秒＋問い2つで30〜50秒 | 3.5〜4.5分 |
| 一気に／区切って | 連絡4つ・各4問 | 読む20〜30秒＋問い4つで30〜50秒 | 3.5〜5.5分 |
| 選んで答える質問 | 4問 | 10〜15秒 | 1分ほど |
| 次の問題を選んだ理由の画面 | 18回 | 3〜5秒 | 1〜1.5分 |
| **合計** | | | **15〜20分ほど**（06 の「合計10分以内」より長い。途中で止めて2〜3回に分けられる） |

- 見積もりのもとにした読む速さ：中学生が1分に300〜500字ほど。聞く出し方は、前もって作った音声の長さ（文章1つ20〜30秒）。
- 案内の文は、実測まで時間を言い切らない下書きにした（子ども向け：「かかる時間は、人によってちがいます」／保護者向け：「まだ人で測っていません（見積もりでは15〜20分ほど）」）。
