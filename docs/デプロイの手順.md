# デプロイ（公開）の手順

> 【下書き】制作1便で書いた手順。まだ公開はしていない。公開には先生のホスティングのアカウントと API キーが要る。

## 作りの形
- 画面は静的なファイル（`public/`）。
- サーバー側の関数は `api/[name].js` の1つ（中身は `lib/api.mjs`）。`/api/joutai`・`/api/tsugi`・`/api/kasetsu`・`/api/tsutae`・`/api/tenken` を受ける。
- API キーはサーバー側の環境変数だけに置く。画面（ブラウザ）には渡さない。
- 記録（ゲームの答え・チェック項目の印）は、使う端末のブラウザの中だけに残る。サーバーには残さない。

## 手元で動かす
1. Node.js 20 以上を入れる。
2. リポジトリのフォルダで `npm install`。
3. Claude を使うときは、`.env.example` を `.env` に写し、`ANTHROPIC_API_KEY=` の後ろにキーを入れる（`.env` は Git に入れない）。
4. `npm start` → ブラウザで `http://localhost:8787` を開く。
5. キーがあっても予備の動き（決まった順）を試したいときは `npm run start:yobi`。

## Vercel に出す
1. Vercel で「Add New → Project」から、GitHub の `chikara-no-switch` を選ぶ。
2. Framework Preset は「Other」。Build Command は空のまま。Output Directory は `vercel.json` に `public` と書いてある。
3. 「Environment Variables」に次を入れる。
   - `ANTHROPIC_API_KEY`：デモ専用のワークスペースで作ったキー
   - `DEMO_KAISU_JOUGEN`（任意）：1つの接続元が1時間に Claude を呼べる回数。決めなければ 60
   - `CLAUDE_MODEL`（任意）：決めなければ `claude-opus-5-5`
4. Deploy を押す。
5. 公開されたアドレスを開き、はじめの画面の下に「いまは Claude を使っています」と出るかを見る。

## Anthropic 側でかける上限（公開デモ）
- Claude Console で、デモ専用のワークスペースを作り、その中でキーを作る。
- そのワークスペースに、月の支出の上限と、1分あたりの回数の上限をかける。
- アプリの中の回数上限（`DEMO_KAISU_JOUGEN`）は、サーバーの関数1つごとの目安で、確実な上限ではない。確実な上限は、ワークスペースの側でかける。
- 上限に達したときや、Claude が使えないときは、自動で決まった順の予備の動きに切りかわる。画面が止まることはない。

## Cloudflare に出すとき（次の便）
- `lib/api.mjs` は `node:fs` で JSON を読んでいる。Cloudflare Pages Functions で動かすには、JSON を import で読む形に変える必要がある。この便では Vercel の形だけを用意した。

## 公開の前に確かめること
- `npm test`（言葉の点検と、比べ方の確かめ）が通る。
- `npm run toshi`（スマホの幅で①〜⑥を最後まで通す確かめ）が通る。Playwright と Chromium が要る。
- キーを入れた状態で `TENKEN_CLAUDE=1 npm run tenken` を走らせ、Claude の出力にも避ける言葉が 0 件であることを見る。
- リポジトリに `.env`・API キー・個人のメールアドレス・実在の子どものデータが入っていない。
