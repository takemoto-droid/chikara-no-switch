# 子どもの安全とプライバシー

> 下書き（先生未確認）。制作4便で書きました。Anthropic の規約・指針は、下の「確かめたページ」を 2026-11-03 に開いて確かめました。

チカラのスイッチは、中学生が授業の中で使うことを考えて作っています。このページでは、子どもの安全とプライバシーのためにしていることを書きます。

## 1. AI を使っていることを、画面に出しています
- どの画面のいちばん下にも「このアプリは AI（Anthropic の Claude）を使っています」と出します。
- 子ども向け・保護者向けの案内にも、AI を使っていることと、名前を AI に送らないことを書いています。
- ゲームで次の問題を Claude が選んだときは「Claude（AI）が次の問題を選んだ理由」と書いてから、理由を出します。AI を使わずに決まった順で出したときは「決まった順」と出します。
- 先生の画面の仮説や伝え方の文には「Claude（AI）が書いた下書き」または「予備の動き（決まった文）」の印と、「参考程度・決めるのは先生」を付けます。

## 2. 子どもが自由に文を打つ入口はありません
- 子どもの画面は、ボタンを押して答える形だけです。文字を打ちこむ欄はありません。
- 困りごとについての質問も、用意した答えから選ぶ形です。「今は答えない」も選べます。
- 子どもが Claude と会話する入口はありません。子どもの画面に出る Claude の文は「次の問題を選んだ理由」だけで、短く、正解の数やほめ言葉を書かないように決めています。
- 文字を打てる欄は、先生の画面の「伝え方の下書き」だけです（先生が下書きを直すため）。

## 3. 記録は端末の中だけ。名前は AI に送りません
- ゲームの答え・回の記録・チェック項目の印は、使っている端末のブラウザの中（localStorage）にだけ残ります。サーバーには残しません。
- Claude に送るのは、出し方ごとの正解の数、選んで答えた質問の答え、チェック項目で当てはまった文だけです。名前や仮の番号は送りません。
- 公開デモのデータは、すべて架空の子どもです。実在の子どものデータは入っていません。

## 4. 先生が全部を見られます
- 先生の画面には、出し方ごとの結果、選んだ答え、チェック項目、Claude の仮説、ゲームで Claude が次を選んだ理由の記録が、すべて出ます。
- Claude の文は、先生に出す下書きです。決めるのは先生です。
- Claude の文は、言葉の正本（避ける言葉の一覧）で機械的に点検してから画面に出します。避ける言葉があれば書き直させ、だめなら決まった文に切りかえます。

## 5. API の入出力は、モデルの学習に使われません
- このアプリは Claude を API（Anthropic の商用のサービス）から使います。
- Anthropic の商用の利用規約（Commercial Terms of Service、2025年6月17日から有効）には「Anthropic may not train models on Customer Content from Services.」と書かれています。Customer Content には、Claude に送った入力と、Claude が返した出力の両方が入ります。

## 6. 未成年に提供する組織向けの指針に沿うために、していること
Anthropic の「Responsible Use of Anthropic's Models: Guidelines for Organizations Serving Minors」（ページの日付 2026年3月16日）が求めることと、このアプリでしていることです。

| 指針が求めること | このアプリでしていること |
|---|---|
| 使う人が想定どおりかを確かめるしくみ（年齢の確認など） | 学校の授業の中で、先生のもとで使う前提です。公開デモは架空のデータだけで、子どもの記録はサーバーに残しません。学校で使うときは、学校のアカウントでのログインを前提にします（期間中は作りません）。 |
| 不適切な内容をふせぐしくみ | 子どもとの自由な会話はありません。問題と選択肢は決まった棚から出します。Claude の文は言葉の正本で点検してから出します。 |
| 問題を見つけて対応するしくみ | 先生の画面で、Claude が書いたものと、次を選んだ理由の記録をすべて見られます。言葉の点検は自動で走ります（`npm test`）。 |
| 安全な使い方についての、未成年向けの説明 | 子ども向けの案内（何をするか・しないこと・AI のこと・相談先）があります。 |
| 子どもの安全のためのシステムプロンプト（Anthropic が用意したもの） | **まだ入れていません。** API キーが来た日に、Anthropic から受け取れるかを確かめ、Claude への頼み方に組み込みます。 |
| 子どもの安全・データ保護の法令を守り、そのことを公開する | 日本の法令（個人情報保護法など）に従います。このページがその公開の場所です。 |
| AI と話していることを使う人に伝える | 1 のとおりです。 |

指針には、守られていないときは Anthropic が確かめに来ることや、アカウントが止められることがあると書かれています。

## 7. 将来、学校で使うとき
- 保護者の同意と、本人へのていねいな説明を前提にします。
- 参加しなくても、成績などで不利益はありません。参加しない子にも、相談先の案内は同じ文で届けます。
- 改正個人情報保護法は 2026年7月に成立し、まだ施行されていません。16歳未満の子どもについては、保護者が同意の相手になります。根拠は、個人情報保護委員会「令和８年 改正個人情報保護法について」（https://www.ppc.go.jp/personalinfo/legal/r8kaiseihogohou ）のページからリンクされた参考資料「16歳未満の者の個人情報等の取扱いの規定関係」（第369回個人情報保護委員会・令和８年９月16日・読替表）です。ページの本文には、この一文はそのままは書かれていません。
